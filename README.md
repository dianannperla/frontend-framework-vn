# Frontend Framework VN

Chào mừng bạn đến với **Frontend Framework VN**! Dự án này nhằm mục đích cung cấp một bộ khung phát triển frontend dễ sử dụng và mạnh mẽ cho các lập trình viên ở Việt Nam.

## Tính năng
- **Cấu trúc dự án rõ ràng**: Giúp nâng cao khả năng bảo trì và phát triển.
- **Hỗ trợ i18n**: Dễ dàng tạo ứng dụng đa ngôn ngữ với giao diện người dùng bằng tiếng Việt và các ngôn ngữ khác.
- **Tính năng xây dựng lại tự động**: Giúp tiết kiệm thời gian phát triển khi kiểm tra các thay đổi.
- **Hướng dẫn lập trình viên**: Cung cấp tài liệu chi tiết và ví dụ minh họa cho từng tính năng.

## Cài đặt
1. Clone dự án: `git clone https://github.com/username/frontend-framework-vn`
2. Cài đặt phụ thuộc: `npm install`
3. Bắt đầu máy chủ phát triển: `npm start`
